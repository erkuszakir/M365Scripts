# Lojistik Operasyon

Cursor Apps üzerinde **Next.js App Router** + Postgres.

## Modüller

- **İş emirleri:** nakliye, depo, yol survey, yol etüdü, yük indirme/bindirme gözetmenliği
- **Depo demirbaş**
- **Satın alma**
- **Para talebi**
- **CRM** (müşteri / aday)

## Şifresiz giriş

Secret gerekmez. İlk Cursor hesabı admin olur.

## Yerel

```bash
npm install
npm run dev
```
