# Lojistik Operasyon

Cursor Apps üzerinde **serverless `/api`** + Vite arayüz.

## Şifresiz giriş

1. Secrets: **SEED_ADMIN_EMAIL** = Cursor e-postanız  
2. Uygulamayı açın → otomatik giriş  
3. (İsteğe bağlı) `JWT_SECRET`

## Yerel

```bash
npm install
SEED_ADMIN_EMAIL=siz@ornek.com npm run dev
```
